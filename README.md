# FinPrime's Engine v3.1 🚀
A standalone Python desktop automation hub built with CustomTkinter, multithreading, and local database logging to replace manual reporting workflows.

## Features
- **Modern GUI:** Custom dark-mode interface built using CustomTkinter.
- **Data Automation:** Streamlines batch file processing and automated reporting.
- **Audit Logging:** Secure local event tracking and schema management.
- **Secure Architecture:** Clean separation of frontend UI and private backend modules.

## Tech Stack
- **Language:** Python 3.x
- **GUI Framework:** CustomTkinter
- **Data Processing:** Pandas / Openpyxl
